===============================================================

PREREQUISITES
-------------
- Python 3.10 or higher  (check: python --version)
- pip                     (check: pip --version)
- Internet connection     (first run downloads AI model ~260MB)


QUICK START (3 STEPS)
----------------------

STEP 1: Extract the zip file
   Right-click miniproj_PRJ382.zip -> Extract All
   You will get a folder called "miniproj"

STEP 2: Open Terminal and install dependencies
   Open Command Prompt (Windows) or Terminal (Mac/Linux)
   Navigate into the extracted folder:

     cd path\to\miniproj

   Then install:

     pip install -r requirements.txt

   NOTE: This may take a few minutes (installs PyTorch, etc.)

STEP 3: Run the project

     python scripts/run_all.py

   The script automatically:
     [0] Creates .env config from .env.example
     [1] Downloads spaCy NLP model (first time only)
     [2] Trains the TF-IDF fallback classifier
     [3] Seeds database with demo users & sample reviews
     [4] Starts FastAPI backend on port 8000
     [5] Starts Streamlit dashboard on port 8501

   Wait until you see "System Operational" in the terminal.


ACCESSING THE APP
-----------------
Open these URLs in your browser:

  Dashboard (Main UI):         http://localhost:8501
  API Docs (Swagger):          http://localhost:8000/docs

Demo Login (click Quick Login buttons in left sidebar):
  Admin:    admin@sentiment.io    / admin123
  Analyst:  analyst@sentiment.io  / analyst123
  Viewer:   viewer@sentiment.io   / viewer123


STOPPING THE APP
----------------
Go back to the terminal and press Ctrl+C

RUNNING TESTS
-------------
  cd miniproj
  python -m pytest tests/ -v


TROUBLESHOOTING
---------------
Problem: "pip install" fails with permission error
  Fix:   pip install --user -r requirements.txt

Problem: Port 8000 or 8501 already in use
  Fix:   Close other apps using those ports

Problem: "ModuleNotFoundError: No module named 'backend'"
  Fix:   Make sure you are inside the miniproj/ folder
         when running the command (not inside backend/)

Problem: First run is very slow
  Normal. DistilBERT model (~260MB) downloads once.
  All subsequent runs are instant.

Problem: "No module named 'en_core_web_sm'"
  Fix:   python -m spacy download en_core_web_sm
